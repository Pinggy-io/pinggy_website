## What changes when an SMP goes public

A public server gets three kinds of load, and an oversold budget host is built for one.

**Volumetric floods (L3 and L4).** UDP floods, SYN floods and amplification attacks just try to fill the pipe. If one is bigger than the node's uplink, every server on the machine lags, so cheap hosts null-route the target: they drop all traffic to your IP, attack and players alike, untill it stops.

**Protocol-level junk (L7).** Bots open real TCP connections to port 25565 and send handshakes, status pings or login attempts, thousands a second. Each looks like a player starting to join, so a generic firewall either lets them through or rate-limits real joins too.

**Real player spikes.** A streamer's chat logs in at once and generates chunks in eight directions. Java Edition runs the world tick on one thread with a 50ms budget, and once a tick runs longer, TPS drops below 20 and everyone feels it.

A host for a public SMP has to filter the first two upstream and give the third enough single-thread CPU and headroom.

## How CloudShield filters attacks without dropping players

CloudShield is CloudNord's in-house DDoS protection, and it sits in front of every server on every plan. The homepage says each server "sits behind always-on filtering at the network edge", that attack traffic "is dropped before it reaches your node, so your players stay connected", and that it's part of the price, not an add-on. The rules are game-aware, tuned for game protocols. Both properties matter.

**Always on** means there's no detection delay. On-demand mitigation waits for traffic to cross a threshold, then reroutes it through a scrubbing centre. Until that happens, players see "Timed out", and the reroute itself can drop sessions. With filtering already in the path, there's nothing to switch on, and nobody gets kicked mid-session.

**Game-aware** is how a filter tells real logins from L7 junk. A rule that understands the Minecraft handshake can drop malformed packets and connection floods while letting a real client through, where a generic rate-limit blocks both.

CloudNord's <a href="https://cloudnord.net/knowledgebase/27/Protecting-Your-Minecraft-Server-From-DDoS-Attacks-with-CloudNord.html" target="_blank">DDoS knowledgebase article</a> also covers the part that's on you:

- Don't post the raw IP. Point a domain at it with an SRV record, so you can move hosts without telling everyone.
- Put a Velocity proxy in front, so the backend's address stays private.
- Whitelist while the server is small, and rate-limit joins with a plugin.

Two smaller notes. Ports are assigned at random by default, and a dedicated IP add-on lets you take 25565. And CloudNord doesn't publish a mitigation capacity figure, so if your community has a history of very large attacks, ask support about it before you move.

## The panel: modpacks, crossplay, backups and SFTP

Every plan gets the same panel, and it covers what an SMP admin does in a normal week.

**Modpacks.** A one-click installer covers over 1,200 packs from CurseForge, Modrinth, FTB, Technic, ATLauncher and VoidsWrath. The switcher works the same way: pick a different pack or version and "the server reinstalls itself without wiping your worlds". The one switch it blocks is to an older Minecraft version than your world was saved in, because that corrupts worlds. Vanilla, Paper, Forge, Fabric and custom JARs are a dropdown away.

**Crossplay.** Java and Bedrock players can share a world through the Minecraft: Crossplay server type, at the same starting price. It runs Paper with <a href="https://geysermc.org/" target="_blank">Geyser</a>, which translates Bedrock packets into Java ones, and Floodgate, which lets Bedrock players join with their Xbox account and no Java licence. Budget about 1GB more RAM than a Java-only server, and plan around plugins rather than mods, since Bedrock players can't load Forge or Fabric content.

**Backups.** Backups are automated and kept off-site. On top of the backups you take or schedule in the panel, CloudNord keeps daily snapshots of every node for 14 days, for "the days nobody pressed the button". Restores are one click, and you can lock a backup so it never rotates out.

**Files.** A full file manager and SFTP come with every plan. You can also split an 8GB server into 6GB of Minecraft and a 2GB MariaDB instance on the private network, handy for CoreProtect or LuckPerms data.
